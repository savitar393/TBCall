> **For agentic workers:** Use superpowers:executing-plans inline, test-driven development, and one independent final read-only review.

**Goal:** Build only the approved browser authentication, proxy, API-client and responsive identity/context shell.

## Review focus

- Encoded traversal, absolute URLs, redirects and attacker-supplied headers cannot change the fixed proxy host/path root.
- Multiple Set-Cookie values, including Expires commas and token deletion on logout, remain independent; private responses cannot be cached.
- Session expiry and account changes cancel/clear prior in-memory queries so stale identity cannot reappear; bootstrap 401 is an expected anonymous state.
- CSRF_INVALID refreshes /me once without replaying mutations; safe messages handle non-JSON/malformed/network errors without leaking server text.
- Production nonce CSP permits hydration and accessible drawer behavior; focus is restored, errors announced and no clinical links appear on mobile/desktop.
